# Brand images

Home Assistant does not read integration icons from the integration itself.
They come from the [home-assistant/brands](https://github.com/home-assistant/brands)
repository, which is also the `brands` check the HACS action performs.

Until the domain is accepted there, Home Assistant shows the generic puzzle
icon for this integration. That is cosmetic and affects nothing else.

## Files

Generated by `scripts/generate_brand_images.py`:

| File | Size | Used for |
|---|---|---|
| `icon.png` | 256x256 | Integration icon |
| `icon@2x.png` | 512x512 | Same, high DPI |
| `logo.png` | 690x256 | Integration page header |
| `logo@2x.png` | 1380x512 | Same, high DPI |

To change the design, edit the script and re-run it:

```bash
python scripts/generate_brand_images.py
```

## Getting them into Home Assistant

1. Fork [home-assistant/brands](https://github.com/home-assistant/brands).
2. Copy this folder to `custom_integrations/sportsradar/` in that fork - the
   folder name has to match the integration domain exactly.
3. Open a pull request. Their CI checks the sizes, transparency and trimming.

Their requirements, which these files already meet:

- PNG with a transparent background, trimmed of surrounding empty space
- `icon` square; `logo` free width, at most 256 (or 512 for `@2x`) tall
- the `@2x` variants exactly double the base ones

Note that the wordmark is deliberately slate and green rather than navy: these
images are shown on both light and dark cards, and navy disappeared on dark
themes.
